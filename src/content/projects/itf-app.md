Plataforma móvil para la International Taekwon-Do Federation. Cubro el 80% del desarrollo frontend usando React Native, conectado a un backend en Python/FastAPI.

El sistema permite gestionar eventos, inscribir atletas, llevar el bracket de torneos y consultar historial de competencias.
